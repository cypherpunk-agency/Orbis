# Orbis

Static map-stories site (see README.md). No build step.

## Hard rule: commercial licences only
Only add code, data, fonts or imagery whose licence permits commercial use. No NC licences, no unclear terms, no "ask us" without a written grant. Copyleft/share-alike (GPL, CC BY-SA, ODbL) needs explicit sign-off. Record every new source in `docs/LICENSING.md` after checking its licence at the primary source.
