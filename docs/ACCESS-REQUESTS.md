# Data behind keys, registration or written permission

Sources that would strengthen Orbis stories but cannot be used as they are: they need an API key, an account, or a written grant. Each row says what the data would add and where access is requested. A grant must be filed (see `docs/LICENSING.md`, use `permission`) before any of this data enters the repository.

Status as of 14 October 2026.
