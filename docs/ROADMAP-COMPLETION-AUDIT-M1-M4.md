The raw package and LICENSE.txt are not present for fresh independent inspection; current publisher access failed and DOI metadata supplies no rights. The coordinator explicitly retained unchanged derived artifacts using that earlier recorded provenance, without a new import or licence relaxation. This supports a reused-artifact review with a visible historical provenance limitation; it is **not** proof of fresh source-file clearance or a newly reproducible raw build. A new raw build must recheck that licence. This audit does not replace the coordinator's documented decision with an invented current clearance.
